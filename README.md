Inspiration
One of the problems I find in quran journey is keep my learning organized.Often, I learn a sourah, then I forget it. I decided that building an website could. But how would it do that?

What it does
it's an amazing interactif website wer user can track their progress in the quran. For now, we only have juzamma. We hope, inshallah, that our website will have all the quran.So, first of all, to understand how you memorize the quran, you will have to pass a little test. This test is very easy with one question. You just have to tell us how much time does it take for you to forget an ayah(don t worry, it doesn t need to be precise). Then, you will be in the main page. Here they will be a progress bar to track your learning of juzamma.The progress bar should be at 0%. It's totaly normal because you didn t pass the quiz. You will have to click the button,check my learning progress and their, you will check the sourah you know. Now, the progress should have change. The website will do an algorithm so that every time you go check, will find the progress decreasing, until it reaches 0.

How we built it
This web site was built using html, css and javascript. For some test, I used python. For bugs and help in generating algorithms, I used google Gemini.

Challenges we ran into
Making a right algorithm was really challenging. But I managed to make one.

Accomplishments that we're proud of

What we learned
